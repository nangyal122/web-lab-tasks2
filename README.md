## 📚 Project Description
This project is developed as part of the *Web Technologies Lab* course.  
It demonstrates the use of *HTML5* for building a complete, well-structured and user-friendly personal student website.  
The project consists of multiple interconnected HTML pages, each focusing on a specific functionality of a student web portal.

---

## 🧩 Features / Pages

### 1. 🏠 Navigation Page
- Provides easy access to all major sections of the website.  
- Includes links to:
  - Home  
  - About  
  - Courses  
  - Contact  

### 2. 👤 Profile Page
- Displays personal information of *Nangyal Khan*.  
- Includes:
  - Name and program details  
  - Profile photo  
  - Contact details (Email, Phone, Location)  
  - Academic background  

### 3. 📝 Registration Form
- A simple and interactive *Student Registration Form* built using HTML <form> elements.  
- Contains fields for:
  - Name  
  - Registration Number  
  - Email & Password  
  - Course Selection  
  - Semester Radio Buttons  
  - Terms & Conditions Checkbox  

### 4. 📅 Weekly Schedule Page
- A tabular representation of the weekly course schedule.  
- Organized by days and times.  
- Includes subject names and a lunch break section.  
- A closing note for *group study/project work*.

---

## 🛠 Technologies Used
- *HTML5*  
- *Basic Inline Styling (CSS)*  
- *No external frameworks used*

## 🚀 How to Run the Project
1. Download or clone the project files.  
2. Open any HTML file (e.g., index.html) in your web browser.  
3. Use the navigation bar to explore all sections of the website.
